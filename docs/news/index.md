# News

Server updates, downtime notices, and major announcements — permanently archived here.

The **live announcement banner** on the [home page](../index.md) shows only what's currently active. Once an announcement is retired from the banner, it lives on here as a dated post.

!!! tip "Categories"
    Use the **Categories** menu in the sidebar to filter by post type: `Announcement`, `Update`, `Downtime`, or `Event`.
