# A Farewell (For Now) — What's Next for the Server

The current world is wrapping up in a few days and a new modded server is taking its place. Same login, same website — new world.

<!-- more -->

## Why This Is Happening

Running a semi-anarchy, vanilla-style server for this long always eventually runs into the same wall: players (understandably) push every mechanic as far as it'll go — mega farms with hundreds of entities, redstone builds that do things the game was never quite built to handle — and at some point the only "fix" is throttling the game itself: spawn caps, tick limits, that sort of thing. That's not a great long-term answer, and honestly, babysitting server performance isn't why I do this.

On top of that, this has always been a personal project for me, and after a year of running this one, I want to go build something different for a while.

## What's Next

The next project is a modded server. Setup, core plugins, mods, and what's even possible to do in it will all be worked out as we go. It likely won't be 24/7 right away.

## What Carries Over — And What Doesn't

Your account and login **carry over**. Authentication stays consistent across every server run here, so your identity isn't lost — it just moves with you. Some of the communication-related plugins carry over too.

What **won't** carry over is your progress — builds, inventories, bases, all of it stays behind with this world. I know that's the hard part.

## The Next Few Days

This server will stay online for a few more days rather than shutting down the moment this goes up — mainly so the people who don't check the website regularly, or who've been on a break, actually have a chance to see this and say their goodbyes.

During that window, a small contained area will be set aside for people to gather, talk, and exchange ways to stay in touch outside the server.

## Downloads

The current world will be made downloadable after shutdown so you can keep a copy, use schematic tools like Litematica to save your base, or drop the folder into your own game and play on it in singleplayer.
