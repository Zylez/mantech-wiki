# Welcome to the Cobblemon Server

The new modded server is live. This is a fresh start — new world, new rules to test-drive, and the same principles as before.

<!-- more -->

## What's Different

- **Modpack:** Cobblemon Official Modpack \[Fabric\] by CobbledStudios. Fabric loader, Minecraft 1.21.1 (see the home page for the current version).
- **Setup:** Beta phase — expect bugs, mod tweaks, and occasional downtime while things settle.
- **Uptime:** May not be 24/7 in the first weeks.

## What Carried Over

- Your account and login work as-is. No re-registering.
- The same admin team, same principles, same website URL.

## What Didn't Carry Over

- Progress from the previous world. Everything is a fresh start.
- Rewards / voting — not currently wired up on the new server. May return later.
