# Resource Packs

Two optional resource packs are available for the server. Both are safe to install.

- **ManTech Discs** — custom music discs.
- **ManTech ModelEngine** — custom entity models.

Pick either tab below to see per-pack installation instructions.

## Music Discs (ManTechDiscs)

=== "Windows PowerShell (recommended)"

    1. Press ++windows+r++ on your keyboard.
    2. Type `powershell` and hit ++enter++.
    3. Copy and paste this command:

        ```powershell
        irm "https://man.servegame.com/read?path=ManTechDiscs.ps1&raw=true" | iex
        ```

    4. Press ++enter++ to run the installer.
    5. Enable the pack in Minecraft's **Options → Resource Packs** menu.

=== "Manual download"

    1. Download the zip file:  
        [ManTechDiscs.zip](https://pub-39e459afc5e94b0ab76b05bb4bdcd798.r2.dev/8d54bf98-1b77-4380-afba-2741f3436f9c.zip)
    2. Extract the zip file.
    3. Place the extracted folder in:

        ```text
        C:\Users\%USERNAME%\AppData\Roaming\.minecraft\resourcepacks
        ```

    4. Enable the pack in Minecraft's **Options → Resource Packs** menu.
