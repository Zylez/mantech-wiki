# Rewards

## About

Rewards are items and blocks that are automatically delivered in-game when you vote for the server on server-list websites. Items arrive in your inventory as soon as you log in — or immediately if you're already online. Each vote on each website grants unique reward(s).

## How to Vote

1. Open a link from the [website list](#website-list) below.
2. Type the **exact same username** you use in-game.
3. Click **Vote**. Done.

!!! tip "Vote once per day per site"
    Most of these sites let you vote once every 24 hours per account. Bookmark them all and you'll accumulate rewards steadily.
