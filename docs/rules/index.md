# Rules & Core Principles

The server runs on a small set of principles rather than a long rule list. If you understand these five, you understand how the server works — and how disputes get resolved.

!!! warning "The one hard boundary"
    Ideological views, dark humor, and heated arguments are tolerated. **Targeted harassment is not.** Slurs, threats, or sustained pile-ons directed at a specific person or group cross the line — everywhere else is fair game.

## The Five Principles

### 1. Radical Freedom

- PvP, building, and raiding are allowed **everywhere**.
- No safe zones. No protected territories. No claim system.
- If you don't want to lose it, don't leave it unattended.

### 2. Ideological Tolerance

- Extreme political and ideological views are permitted in global chat.
- **Hard boundary**: no targeting groups or individuals with slurs, threats, or sustained harassment.

### 3. Death & Consequences

- Inventory drops fully on death — standard vanilla behavior.
- Griefing, theft, and betrayal are **legal**. Trust is earned, not granted.

### 4. Absolute Independence

- The server has **no official Discord**, no official guilds, and no "partnered" communities.
- Any group claiming to represent server administration is unofficial and unaffiliated.

### 5. Verified Authority

- Only two people have administrative power: **Auzer1** and **FunOD**.
- Anyone else claiming to be a moderator, "helper," or staff is lying.
- We do not run hidden or alt staff accounts for moderation.

## Conflict Resolution

How disputes are actually handled when they escalate:

| Situation | Handling |
| --- | --- |
| In-game conflict, chat drama, PvP grudges | Chat/world isolation is the primary tool |
| Evidence of **off-server** attacks (DMs, forums, doxxing attempts) | Permanent cross-platform ban |
| Impersonation of staff | Immediate ban |
| Reports without evidence | Not actioned |

## What Is *Not* a Rule

To save everyone time, these things are **allowed** and are not going to be actioned:

- [x] Killing other players, anywhere, for any reason
- [x] Building near, on top of, or inside another player's base
- [x] Stealing, scamming in trades, betraying alliances
- [x] Trash-talking in chat within the hard-boundary limits above
- [x] Using client-side mods that pass the AntiCheat (see [FAQ](../faq/index.md))

If you're looking for a protected, moderated experience, this is not the right server for you — and that's fine.
