## Reporting an Issue

Before reaching out, check whether your issue is covered on one of these pages:

- [Rules](../rules/index.md) — for questions about what is and isn't allowed.
- [FAQ](../faq/index.md) — for common questions about server operation.
- [News](../news/index.md) — for downtime notices, updates, and known issues.

If none of those cover it, contact an admin using the spoiler above.

!!! warning "What we cannot help with"
    - Player disputes (see [Rules → Conflict Resolution](../rules/index.md#conflict-resolution))
    - Recovering griefed builds or stolen inventory — this is by design
    - Issues with third-party launchers or your local Minecraft installation
