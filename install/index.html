    Install¶

    Cursed Walking on this server is not the same pack you'd install from CurseForge. We stripped out ambience mods, shader mods, and other graphics-heavy content so the pack runs on modest hardware — most players see around 60 FPS on 8 GB RAM. Content stays intact; visual bloat doesn't. Because of this, installing the official CurseForge modpack will not let you join — you'll get rejected on the connection mod check.

    The four setup paths below give you our modified pack instead. Pick whichever fits how you already play.

    Two things that will break your install

    1. Do not install OptiFine. It crashes with the shader/rendering stack that ships in Cursed Walking. Even though we've removed most graphics mods, the ones that remain still conflict with OptiFine.
    2. The server runs Minecraft 1.20.1 on Forge. Wrong version, wrong loader (NeoForge/Fabric), or missing mods → rejected at connect.

    Pick your install path¶

    Easiest — everything set up already. A pre-configured Forge 1.20.1 instance with AutoModpack, our modified mod list, and any needed configs already inside. Import into your launcher and launch.

    Download link not currently available

    The preloaded pack is offered when we have a working build to share. Use the AutoModpack or Standard tab in the meantime — both get you to the same place.

    When available, the flow is:

    1. Download the preloaded modpack zip from the link posted here.
    2. In your launcher: Add instance → Import from zip and select the file.
    3. Give it at least 6 GB of RAM (8 GB if you have it).
    4. Launch and add the server (address on the home page).

    Recommended for most players. Install AutoModpack once, and it syncs the mods from the server on every launch. Version bumps happen automatically — you don't touch the mods folder yourself.

    1. In your launcher, create a Forge 1.20.1 instance. See Launchers we recommend below if you don't already have one set up.
    2. Allocate at least 6 GB of RAM to the instance (8 GB is comfortable).
    3. Download AutoModpack for Forge 1.20.1 from Modrinth or CurseForge.
    4. Drop the .jar into your instance's mods/ folder.
    5. Launch the instance. When you first connect to the server, AutoModpack will download the rest of the mod list into a subfolder and prompt you to restart.
    6. Restart, connect again — you're in.

    Any client-side-only mods you add (Sodium-alternatives, cosmetic HUDs, keybind managers) can live alongside AutoModpack's synced mods without issue.

    Skip AutoModpack. Build the mod list yourself from the live list further down this page. Fine for people who want full control over what's in the mods folder, or who don't want AutoModpack running.

    1. In your launcher, create a Forge 1.20.1 instance.
    2. Allocate at least 6 GB of RAM (8 GB comfortable).
    3. Scroll to Required mods below. Every chip is a mod — click through, download the version listed, drop each .jar into the instance's mods/ folder.
    4. Launch and connect.

    You'll need to re-do the sync any time we bump the pack. Consider the AutoModpack tab if that sounds annoying.

    No launcher at all. Straight Minecraft + Forge installer + manual mods. For portable setups, unusual OSes, or when you want to know every file that landed on disk.

    1. Install Java 17 (Adoptium/Temurin recommended).
    2. Grab the Forge 1.20.1 installer from the Forge downloads page — pick the recommended build for 1.20.1.
    3. Run the installer → Install client into a fresh game directory.
    4. In that directory, create a mods/ folder. Download every mod from Required mods into it.
    5. Point your Minecraft launcher (vanilla, or whatever) at the Forge 1.20.1 profile and launch.
    6. Connect to the server.

    This is the most work. Use it only when the other tabs don't apply.

    Launchers we recommend¶

    Any launcher that can install Forge 1.20.1 and connect to a cracked / offline-mode server will work. Popular choices among players:

    • CurseForge App — free, imports Forge instances easily, supports offline mode.
    • Prism Launcher — open source, actively maintained, cracked-friendly.
    • TLauncher — well-known among cracked players; has built-in Forge install.
    • ATLauncher — supports Forge and offline mode.
    • SKLauncher — lightweight, cracked-friendly.

    If you're brand new to modded Minecraft, the CurseForge App or Prism Launcher are the two smoothest choices.

    Required mods¶

    Every mod currently on the server, pulled live from the actual mods/ folder on the box. Sync happens every five minutes.

    Client-side mods are welcome

    You can add any client-side-only mod on top of this list — cosmetic HUDs, keybind managers, minimap replacements, and so on. Only mods that add content, change recipes, or affect the world will get you rejected by the server's mod check.

    Verify your install¶

    Run through these before your first connection attempt. Most first-time issues fall out of exactly one of them.

    • Minecraft version reads 1.20.1.
    • Loader reads Forge (not NeoForge, not Fabric).
    • Allocated at least 6 GB of RAM to the instance.
    • Every mod in the list above is present in your mods/ folder — or AutoModpack has synced them.
    • OptiFine is not installed anywhere in the mods folder.
    • You logged in with any Minecraft profile — cracked accounts are fine.

    Troubleshooting¶

    Game crashes on launch with a shader or rendering error

    OptiFine is almost certainly in your mods folder. Remove it. The pack already includes what it needs for shaders — no third-party additions needed.

    ??? question '"Connection refused" or "Server not responding"' Check the home page — the server status card shows if the box is down. This modpack is in testing and the server runs on a schedule, not 24/7. If the card says online and you still can't connect: double-check the address for typos, verify the mod list matches, and try a fresh launcher restart.

    ??? question '"Missing mods" or "Mod rejections" on connect' Your mods folder doesn't match the server's list. Either sync via AutoModpack, or diff your folder against the live Required mods list above and add whatever's missing.

    Extreme lag or slow chunk loading

    Give the instance more memory — 8 GB is safe on most machines with 16 GB total. If you're on integrated graphics, expect low framerates during horde events; nothing we can do about that server-side.

    Java version errors

    Cursed Walking on 1.20.1 needs Java 17. The CurseForge app and Prism handle this automatically. For manual installs, install Adoptium/Temurin 17 and point your launcher at it.

    AutoModpack refuses to download

    Make sure your AutoModpack version is for Forge, not Fabric or NeoForge. Also verify the instance actually reached the server once — AutoModpack only knows what to fetch after a successful handshake.

    I tried everything and it still won't work

    Head over to Support — bring your latest crash log. Without it we're guessing.
